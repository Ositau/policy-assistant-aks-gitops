# Policy Assistant on AKS with Argo CD and Helm

GitOps deployment of the [Policy Assistant](https://github.com/Ositau/azure-openai-policy-assistant) to Azure Kubernetes Service,
across four environments (dev, test, stage, prod), with Terraform for the platform, Helm for packaging,
Argo CD for deployment and GitHub Actions for building and promoting. No keys or client secrets anywhere.

Work in progress.
